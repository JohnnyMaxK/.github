# Security policy

## Reporting a vulnerability

Please do not open a public issue for a security problem.

Write to **johnny@jmk.studio** with:

- the repository and, if possible, the file or URL concerned;
- what an attacker can do, and the steps to reproduce it;
- your name or handle if you would like to be credited.

You will get an acknowledgement within 5 working days. Please give a reasonable delay to fix the problem before any public disclosure.

## Supported versions

Only the latest version on the default branch of each repository is maintained.
