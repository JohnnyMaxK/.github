# .github

Default community health files for the public repositories of [JohnnyMaxK](https://github.com/JohnnyMaxK). A repository with its own file of the same name overrides the default here.

- [SECURITY.md](SECURITY.md): how to report a vulnerability.
- [CONTRIBUTING.md](CONTRIBUTING.md): how to contribute.
- [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md): code of conduct.
